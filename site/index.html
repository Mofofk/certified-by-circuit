Rule
  1. The supplier enters the lab's test values for a batch. The buyer's minimums come from the standard (EN 388 gloves, arc-flash suits, SCBA sets) or the buyer's own purchase spec.
  2. All 64 input bits go into one TapeOut circuit on X Layer: four 8-bit "measured ≥ required" comparators plus an AND gate. It is 224 NAND gates and nothing else.
  3. The circuit's eval() returns PASS or FAIL for each parameter and overall. Anyone can re-run it for free, so nobody can fake the result.
  4. The batch record and the lab report's SHA-256 are stored on this DeWEB site's container. The QR label on the carton opens this page with the batch ID.
  5. Buyers raise problems with the supplier's container over TapeSend.

"Lower is better" limits, such as afterflame seconds, are entered as 255 minus the value, so the same comparator checks them.
